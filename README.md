# NEXA — лендинг SaaS-продукта

Адаптивный маркетинговый лендинг на React + Vite. Тёмный CTA-блок, «живое» окно продукта в hero, анимации на CSS.

## Запуск

```bash
npm install
npm run dev
```

`npm run build` — production-сборка в `dist/`.

## Что внутри

- Мобильное меню, плавная навигация по секциям.
- Переключатель тарифов «месяц / год» с пересчётом цены.
- Интерактивный FAQ-аккордеон.
- Форма заявки с локальной проверкой email и экраном успеха.

Стек: React 18, Vite, чистый CSS (без UI-библиотек). Шрифт Manrope подключается через Google Fonts, есть системный fallback.
